### 任务4 分支与合并
```bash
git checkout -b feature-blink
（创建名为 feature-blink 的新分支，并立即切换到该分支）
git checkout main
（从功能分支切换回主分支 main）
git log --oneline
（用一行一条的形式查看提交历史）
git diff main feature-blink
（比较 main 和 feature-blink 两个分支之间的代码差异）
git merge feature-blink
（把 feature-blink 的提交合并到当前分支；执行前必须位于 main）
```
### 任务5 体验回退
```bash
git log --oneline
（用一行一条的形式查看提交历史）
git reset --hard HEAD~1
（让当前分支退回到上一个提交，并永久丢弃最新提交及当前未提交的修改）
```

### 今天学习的 git 命令
| 命令 | 作用 | 什么时候用 |
|---|---|---|
| `git clone <仓库地址>` | 将远程仓库复制到本地 | 第一次获取已有远程项目时 |
| `git init` | 在当前目录初始化 Git 仓库 | 本地已有项目，需要开始使用 Git 管理时 |
| `git status` | 查看仓库、暂存区和文件状态 | 提交前后检查文件变化时 |
| `git add .` | 暂存当前目录中的所有修改 | 准备提交全部修改时 |
| `git add <文件路径>` | 暂存指定文件 | 只想提交某个文件时 |
| `git commit -m "提交说明"` | 创建一条本地提交记录 | 完成一次修改并暂存后 |
| `git checkout -b <分支名>` | 创建并切换到新分支 | 开始开发新功能时 |
| `git checkout main` | 切换到主分支 | 准备比较或合并功能分支时 |
| `git branch -d <分支名>` | 删除已经合并的本地分支 | 功能分支不再需要时 |
| `git log --oneline` | 简洁地查看提交历史 | 查看提交顺序或准备回退时 |
| `git diff main <分支名>` | 比较两个分支的代码差异 | 合并分支前检查修改时 |
| `git merge <分支名>` | 将指定分支合并到当前分支 | 把功能分支合并回 `main` 时 |
| `git reset --hard HEAD~1` | 回退到上一个提交并丢弃修改 | 确认不需要最后一次提交时，谨慎使用 |
| `git remote add origin <仓库地址>` | 关联远程仓库 | 本地仓库第一次连接 GitHub 时 |
| `git remote -v` | 查看远程仓库地址 | 检查远程仓库是否配置正确时 |
| `git push -u origin main` | 首次推送并建立分支跟踪关系 | 第一次将 `main` 推送到远程时 |
| `git push` | 将本地提交推送到远程 | 日常上传已经提交的修改时 |
| `git pull` | 获取并合并远程更新 | 远程仓库有新提交，需要同步到本地时 |
