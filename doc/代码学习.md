# 代码学习
## main.c 学习
芯片复位进入main - 配置MPU - 初始化HAL - 配置系统时钟 - 初始化GPIO - 初始化蜂鸣器 - 调用一次 user_beep - LED1~LED4 依次闪烁 - 根据负反馈继续闪烁
### 宏定义参数
#define LED_COUNT   4U
#define BLINK_TIMES 3U
#define DELAY_MS    500U
#define BEEP_MS     120U
U 表示无符号整数
| 宏             |     数值 | 作用            |
| ------------- | -----: | ------------- |
| `LED_COUNT`   |      4 | LED 总数量       |
| `BLINK_TIMES` |      3 | 每个 LED 每轮闪烁次数 |
| `DELAY_MS`    | 500 ms | 初始亮、灭等待时间     |
| `BEEP_MS`     | 120 ms | 蜂鸣器鸣叫时间       |
### main函数运行过程
定义运行变量
uint8_t current_led = 1U;  current_led：当前操作的LED 编号。
uint8_t blink_times = BLINK_TIMES;  blink_times：每个 LED 闪烁 3 次。
uint32_t delay_ms = DELAY_MS;  delay_ms：当前亮灭等待时间，初始为 500 ms。
const uint8_t led_count = LED_COUNT;  led_count：LED 总数，为 4。
配置内存保护单元
MPU_Config();
MPU 是内存保护单元。这里设置了一个禁止访问、禁止执行的区域，主要作用是防止 CPU 意外访问无效地址，同时降低错误预取或非法内存访问造成异常的风险。
初始化 HAL
HAL_Init();
作用：初始化 HAL 库内部状态/配置系统节拍定时器/设置中断优先级/为 HAL_Delay() 提供毫秒计时基础。
配置系统时钟
SystemClock_Config();
程序以 HSI 内部高速时钟作为 PLL 输入:
RCC_OscInitStruct.PLL.PLLM = 4;
RCC_OscInitStruct.PLL.PLLN = 34;
RCC_OscInitStruct.PLL.PLLFRACN = 3072;
RCC_OscInitStruct.PLL.PLLP = 1;
如果时钟配置失败，程序会进入以下程序，然后关闭中断并停留在死循环中:
Error_Handler();
初始化 GPIO 和蜂鸣器
MX_GPIO_Init();  初始化 LED、蜂鸣器等设备使用的 GPIO。
buzzer_init();  初始化蜂鸣器，并确保蜂鸣器处于关闭状态，防止上电时意外发声。
调用弱函数 user_beep
user_beep();
### 主循环
while (1)
{
    current_led = 1U;

    while (current_led <= led_count)
    {
        blink_led(current_led, blink_times, delay_ms);
        current_led++;
    }

    beep(BEEP_MS);

    if (delay_ms > 100U)
    {
        delay_ms -= 20U;
    }
    else
    {
        delay_ms = DELAY_MS;
    }
}
将当前 LED 编号恢复为 1 - LED1 闪烁 3 次 - LED2 闪烁 3 次 - LED3 闪烁 3 次 - LED4 闪烁 3 次 - 蜂鸣器鸣叫 120 ms - 将亮灭间隔减少 20 ms - 返回步骤 1，继续下一轮。
LED 闪烁函数
static void blink_led(uint8_t led_num, uint8_t times,
                      uint32_t delay_ms)
{
    uint16_t i;

    if (led_num > LED_COUNT)
    {
        return;
    }

    for (i = 0U; i < times; i++)
    {
        led_on(led_num);
        HAL_Delay(delay_ms);

        led_off(led_num);
        HAL_Delay(delay_ms);
    }
}
蜂鸣器函数
static void beep(uint32_t duration_ms)
{
    buzzer_on();
    HAL_Delay(duration_ms);
    buzzer_off();
}
### 加速规律
if (delay_ms > 100U)
{
    delay_ms -= 20U;
}
else
{
    delay_ms = DELAY_MS;
}
### 错误处理
void Error_Handler(void)
{
    __disable_irq();

    while (1)
    {
    }
}
出现严重初始化错误时：关闭所有中断 - 进入无限循环 - 程序不再继续运行
